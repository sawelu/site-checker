# Site Checker

Веб-приложение для комплексной проверки сайта и его домена: DNS, почтовые настройки,
SSL-сертификат, доступность HTTP/HTTPS, пинг и открытые порты.

Введи домен — и получишь сводный отчёт со статусом каждой проверки.

## Возможности

| Модуль | Что показывает |
|---|---|
| Сводка | Итоговый вердикт (Сайт в порядке / Есть замечания / Сайт неисправен) + список проблем |
| DNS | NS-серверы и их проверка напрямую (IP, ответ, задержка), а также A/AAAA/CNAME/MX/NS/TXT/SOA/CAA |
| Почта | SPF, DMARC (у `_dmarc.`) и DKIM (у `default._domainkey.`) |
| HTTP/HTTPS | Код ответа, цепочка редиректов, время загрузки, размер, заголовок Server, конечный URL |
| SSL | Валидность, даты, издатель, владелец, все SAN-домены, TLS-версия, длина цепочки. Предупреждение при остатке < 30 дней |
| Пинг | ICMP доступность хоста |
| Порты | 12 портов: 21, 22, 25, 80, 110, 143, 443, 993, 995, 3306, 5432, 8080 |
| WHOIS | Регистратор, даты регистрации/истечения, статусы |

## Установка и запуск

```bash
cd dns-checker

# (рекомендуется) виртуальное окружение
# python3 -m venv .venv && .venv/bin/activate

pip install -r requirements.txt
python3 app.py
```

Открой `http://127.0.0.1:5000`, введи домен (например `github.com`) и нажми **Проверить**.

Приложение нормализует ввод: `https://www.example.com/путь` → `example.com`.
IP-адреса и невалидные строки отклоняются с понятным сообщением.

## Структура

```
app.py                 — вся логика приложения (Flask)
templates/index.html   — интерфейс
static/style.css       — стили
requirements.txt       — зависимости
CLI-CHEATSHEET.md      — те же проверки, но командами терминала
```

## Требования

- Python 3.9+
- Доступ к DNS (UDP 53), портам TCP, ICMP (для пинга), WHOIS (TCP 43)

## CLI-инструкции без программы

Все проверки, которые делает приложение, можно выполнить стандартными утилитами —
см. **[CLI-CHEATSHEET.md](CLI-CHEATSHEET.md)**.
